# Code of conduct

Little Chits follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep criticism about the work. Harassment, personal attacks and
discriminatory language are not welcome in issues, pull requests, discussions or anywhere else the project lives.

To report a problem, contact the maintainer through GitHub (a private vulnerability report reaches them privately,
and is fine to use for conduct reports too). Reports are kept confidential.
