# LITTLE CHITS provenance

This repository is the canonical implementation and design authority for **Little Chits**.

## Lineage

- Little Chits was developed in a private repository from mid-2026: a first Day-1 implementation, then the v2
  rebuild that became `main`, then the post-plan upgrades and the research layer described in `CURRENT.md`.
- This public repository starts from one snapshot of that work, published as a single commit on 2026-10-02 under
  the MIT licence. The private history (its branches, pull requests and issues) stays private and is not part of
  this repository. Pull request and issue numbers mentioned in the docs (#5, #6 and later) refer to that history.
- From the snapshot on, all implementation work continues here, from protected `main`, through reviewed, green
  pull requests.

## Authority

For current project truth, read this repository's `CURRENT.md`, `HANDOFF.md`, `docs/FIXES_2026-09-30.md`, and
`docs/RESEARCH_PLAN_2026-09-30.md`.
